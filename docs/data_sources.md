# データソース一覧

## 公開データベース

### 1. 社会福祉法人現況報告書等情報検索（WAM NET）
- **URL**: https://www.wam.go.jp/
- **対象**: 社会福祉法人（全国）
- **データ形式**: CSV（申請後ダウンロード）
- **更新頻度**: 年次（事業年度終了後1〜2年）
- **主要項目**:
  - 法人番号、法人名
  - 事業年度、事業収益（売上）
  - 経常収支差額、純資産額
  - 常勤換算職員数

### 2. 介護サービス情報公表システム
- **URL**: https://www.kaigo.mhlw.go.jp/
- **対象**: 介護サービス事業所（全国）
- **データ形式**: CSV（オープンデータ）
- **更新頻度**: 年数回
- **主要項目**:
  - 事業所番号、事業所名
  - 法人番号
  - サービス種別（訪問介護、デイサービス等）
  - 定員、開設日
  - 所在地

### 3. 障害福祉サービス等情報公表システム
- **URL**: https://www.wam.go.jp/ (WAM NET内)
- **対象**: 障害福祉サービス事業所（全国）
- **データ形式**: CSV（オープンデータ）
- **更新頻度**: 年数回
- **主要項目**:
  - 事業所番号、事業所名
  - 法人番号
  - サービス種別
  - 定員、開設日
  - 所在地

### 4. e-Stat（介護サービス施設・事業所調査）
- **URL**: https://www.e-stat.go.jp/
- **対象**: 全国集計統計
- **データ形式**: CSV、API
- **更新頻度**: 年次
- **主要項目**:
  - 都道府県別、市区町村別の集計
  - サービス種別別の集計
  - 施設数、定員数

## データ品質上の注意

- **法人番号**: 2015年施行前のデータは欠番が多い
- **重複**: 複数システムに同じ法人・事業所が登録されている可能性
- **遅延**: 新設・廃止情報の反映に時間がかかる
- **欠落**: 民間施設やNPO法人運営施設の情報が不完全
